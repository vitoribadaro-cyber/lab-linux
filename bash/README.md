## 🐧 Auditoria Linux

Projeto desenvolvido em Bash Script para realizar uma auditoria básica do sistema operacional Linux através de um menu interativo.

---

## 📋 Funcionalidades

- Informações do Sistema
- Processos em Execução
- Usuários Logados
- Espaço em Disco
- Memória RAM
- Relatório Geral

---

## 🛠 Conceitos praticados

Durante o desenvolvimento deste projeto foram utilizados:

- Variáveis
- Funções
- Estruturas de decisão (`case`)
- Laços de repetição (`while`)
- Entrada de dados (`read`)
- Organização de código
- Reutilização de funções
- Comandos de administração Linux

---

## ▶️ Como executar

Entre na pasta:

```bash
cd bash
```

Dê permissão de execução:

```bash
chmod +x auditoria_linux
```

Execute:

```bash
./auditoria_linux
```
